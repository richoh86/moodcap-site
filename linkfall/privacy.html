Privacy Policy

Effective date: October 26, 2026

This policy explains what the PROJECT LINKFALL iPhone game keeps on your device, what its optional gameplay analytics sends if you turn it on, and how long that information is kept.

PROJECT LINKFALL has no account, no advertising, no in-app purchases and no tracking across other companies' apps or websites. Gameplay analytics is off by default. It is sent only from app versions that include the analytics setting, and only after you turn it on.

Information stored on your device

The game stores your settings, progress, a resumable run and a limited local gameplay diagnostics log on your iPhone. These files are not sent to us and are not an account or cloud-save service. Your device's own backup settings may include app data, independently of the game.

Optional gameplay analytics

If you turn on analytics in Settings, the game sends limited gameplay events so we can improve onboarding, difficulty balance, reliability and retention. Nothing recorded before you turned it on is uploaded.

What is sent

  • Analytics enrollment, the in-game onboarding steps and onboarding completion
  • Session start, and session end with a duration range and a run-count range
  • Run start and run end: sector, difficulty, loadout, outcome, the wave reached, a duration range, and ranges for hits taken, LINK BREAKs and pauses
  • Wave start and clear, and boss phase start and clear
  • Defeats, with a fixed cause category (for example, the enemy attack type)
  • Retry, quit, pause and resume, with the wave and a duration range
  • LINK BREAK use, with the wave
  • Save or progress failures, as fixed error codes
  • Which setting was changed (the setting's name only, not its value)
  • Coarse return information: the week you turned on analytics, and whether the app was used again around day 1 or day 7

Every event also carries the analytics schema version, the app version and build number, the distribution channel (TestFlight or App Store), and a random number generated for that single event. The random number is used only to discard duplicate deliveries of the same event. A new, unrelated number is created for every event, so it is not an installation, device or session identifier.

What is not sent

Analytics never includes your name, email address, account, photos or other personal content, advertising identifier, a persistent installation or device identifier, a session identifier, device model, location, language or region, touch positions, precise event times, free text, or crash reports.

Where it goes

Events go to a dedicated analytics service for PROJECT LINKFALL running on Cloudflare (Cloudflare Workers and D1). The analytics database records only the UTC day and week on which an event was received; it has no fields for IP address, user agent or other request headers. Request logging is turned off for this service.

Like any internet service, Cloudflare processes network information, such as your IP address, in order to deliver and protect traffic. That processing is governed by Cloudflare's privacy policy, and we cannot guarantee how long Cloudflare itself keeps such information.

How it is used

Analytics is used only to understand and improve the game: for example, where players find a wave too hard, which settings are changed, and whether save errors occur. Reports show grouped totals; groups with fewer than 20 events are hidden. Return rates are estimates among installations that turned analytics on. They are not counts of individual people or exact daily users. Analytics is not used for advertising, is not sold, and is not combined with data from other apps.

How long information is kept

If the daily job is delayed, deletion happens on its next successful run. Cloudflare's database recovery feature can keep earlier states of the database for up to 7 additional days on the plan used for this service, after which they are no longer available.

Your choices

  • Analytics is off unless you turn it on in Settings.
  • Turning it off stops future sending and deletes any events still waiting on your device.
  • Because no installation identifier is sent, we cannot find which previously received events came from your device, so we cannot delete them individually. They are deleted on the schedule above.

Test builds

Development builds and automated tests do not send analytics. Events from TestFlight beta builds are stored separately from App Store events.

Advertising, purchases and tracking

PROJECT LINKFALL contains no advertising, no in-app purchases and no third-party analytics or advertising SDKs. It does not use your advertising identifier or track you across other companies' apps or websites. If this changes, this policy will be updated before the change is released.

Support email and this website

If you email support, we use your message and anything you choose to include to respond to you. This website is hosted on GitHub Pages; GitHub processes visitor requests under the GitHub General Privacy Statement. These pages add no analytics scripts, tracking cookies or external fonts.

Changes to this policy

We will update this page and its effective date when the game's handling of information changes. A new kind of analytics data will not be collected without updating this policy first.
